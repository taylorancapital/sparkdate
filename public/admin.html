CSV format help
First row must be a header. Recognized columns (any order; extras ignored): name, address, city, type, contact_name, contact_email, contact_phone, notes, stars, description Only name is required. stars is a 0–5 Google rating (e.g. 4.7). description is the customer-facing blurb — it gets pulled into event descriptions. notes stays internal (admin-only). Quoted fields are supported, e.g. "Smith, Jr.","123 Main St".

With Overwrite existing ON, rows whose names already exist will merge new fields (email, phone, stars, etc) into the existing venue — preserving pipeline state (status, contacted_at). Blank cells never overwrite. Turn OFF to skip duplicates entirely.
